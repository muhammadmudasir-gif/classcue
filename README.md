# ClassCue

A gentle coursework planner for students. Track assignments, exams, projects, readings, and due dates in one calm, searchable-at-a-glance list.

## Features
- Add coursework with type, course, and due date
- Filter all, to-do, or completed items
- Completion tracking and due-date countdowns
- Summary counts for open, upcoming, and completed work
- Data persists in the browser with `localStorage`; no account or server required
- Responsive layout and accessible form controls

## Run locally
Open `index.html` in any modern browser. No build step or dependencies required.

## Privacy
Items remain in the browser on the device where they were entered. Clearing browser storage removes them.

## Stack
HTML, CSS, vanilla JavaScript.
